# mwinukaCapture

**mwinukaCapture** is a security tool designed to capture webcam images of anyone attempting to access a computer. It stores timestamped images in a dedicated folder for security monitoring and forensic purposes.

---

## Features

- Captures intruder images using the webcam
- Automatically saves images with timestamp
- Linux installer (`.deb`) for easy distribution
- Windows version (`.exe`) supported
- Portable and lightweight

---

## Installation (Linux)

Download the `.deb` package and run:

```bash
sudo dpkg -i mwinukaCapture_1.0_all.deb
